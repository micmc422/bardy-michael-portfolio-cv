**TW2 — Technologies du Web 2** est la refonte de mon cours de **Licence** à l'**Université Champollion (Albi)**. Comme TW3, il est passé de **Nextra à Fumadocs** pour une meilleure navigation, et s'est doté d'un **système de quiz et d'exercices suivis** : l'étudiant repère immédiatement ce qu'il doit réviser.

## 🎯 Objectifs

* Offrir des **fondations front-end** solides et accessibles
* Faciliter la **navigation** dans les modules du cours
* Intégrer des **quiz auto-évalués** et des **exercices suivis**
* Aider les étudiants à **cibler les points ratés** et à réviser efficacement

## 📋 Vue d'ensemble

| Élément | Détail |
| --- | --- |
| Public | Étudiants L — Université Champollion (Albi) |
| Rôle | Développeur & concepteur pédagogique |
| Ancien framework | Nextra |
| Nouveau framework | **Fumadocs** |
| Format | Cours modulaires en MDX + quiz + suivi |
| Livrable | Plateforme en ligne + tableau de bord |

## 🧩 Fonctionnalités clés

* **Navigation Fumadocs** : sommaire latéral, recherche et progression par chapitre
* **Quiz intégrés** : QCM à correction immédiate et explications détaillées
* **Exercices suivis** : scores et chapitres terminés mémorisés dans le navigateur
* **Ciblage des révisions** : les points à revoir sont mis en évidence automatiquement
* **Contenus MDX** : cours riches et maintenables, sans friction éditoriale
* **Responsive & accessible** : lecture optimale sur tous les écrans

## 🧠 Modules abordés

| Module | Contenu |
| --- | --- |
| Introduction au Web | Fonctionnement du web, HTTP, navigateurs et outils |
| HTML sémantique | Structure de document, accessibilité, balises modernes |
| CSS : Fondamentaux | Sélecteurs, cascade, spécificité, modèle de boîte |
| Flexbox & Grid | Mise en page bidimensionnelle et responsive design |
| JavaScript : Bases | Types, variables, opérateurs, structures de contrôle |
| Manipulation du DOM | Sélection, modification et création d'éléments HTML |
| Fonctions | Déclaration, portée, closures, fonctions fléchées |
| Événements | Écoute, propagation et délégation d'événements |
| Modules & Classes | Modules ES6, import/export, classes et héritage |
| JSON & Stockage local | JSON, localStorage, sessionStorage |
| Asynchronicité | Callbacks, Promises, async/await et fetch API |

## ⚡ Défis relevés

* Repenser la **navigation** dans une masse de cours importante sans perdre l'étudiant
* Garantir une **migration fidèle** du contenu Nextra vers Fumadocs
* Concevoir un **suivi de progression** léger, sans backend (stockage navigateur)
* Préserver **performance et accessibilité** sur tous les appareils
