**H2team**, spécialiste de l'ingénierie hydrogène, avait besoin d'un site vitrine à la hauteur de son expertise et capable de s'adresser à des clients francophones comme anglophones. J'ai construit un front-end **Next.js** alimenté par un **WordPress en mode headless**, pour allier performance, sécurité et confort éditorial.

## 🎯 Objectifs

* Créer une **plateforme multilingue** fluide et accessible
* Mettre en avant les services avec un **design professionnel**
* Offrir une **architecture évolutive** et facile à maintenir
* Garantir **rapidité, sécurité et visibilité SEO**

## 📋 Vue d'ensemble

| Élément | Détail |
| --- | --- |
| Public | B2B — ingénierie hydrogène |
| Rôle | Développeur full-stack |
| CMS | WordPress (headless) |
| Langues | Français + Anglais |
| Hébergement | Vercel |

## 🧩 Fonctionnalités clés

* **Multilingue** : navigation fluide entre langues via *i18next*
* **CMS headless** : contenus gérés dans *WordPress* pour plus de flexibilité
* **Performances** : pages pré-générées avec *Next.js* (chargements ultra-rapides)
* **SEO-friendly** : optimisation technique et sémantique
* **Sécurité** : back-office WordPress isolé pour limiter les failles
* **Scalabilité** : architecture pensée pour évoluer avec le projet

## ⚙️ Stack technique

| Technologie | Usage | Type |
| --- | --- | --- |
| Next.js | Rendu hybride performant | Framework |
| WordPress (headless) | Gestion centralisée du contenu | CMS |
| GraphQL | Requêtes souples et performantes | API |
| Tailwind CSS | Design moderne et responsive | Style |
| i18next | Internationalisation du site | i18n |
| Vercel | Déploiement simple et rapide | Infra |
