Votre site WordPress rame, les mises à jour cassent des plugins et la facture d'hébergement grimpe ? La migration vers Next.js est souvent l'occasion de repartir sur des bases saines : un site plus rapide, plus sûr et moins coûteux à faire tourner.

## Pourquoi quitter WordPress ?

WordPress motorise un tiers du web, mais ce n'est pas toujours le bon outil. Pour un site vitrine ou un portfolio, la stack se retourne contre vous : plugins à maintenir, failles de sécurité récurrentes, temps de chargement plombés par le thème.

Next.js prend le contre-pied : les pages sont générées à l'avance et servies depuis un CDN. Résultat concret sur les Core Web Vitals :

| Critère | WordPress (thème classique) | Next.js statique |
| --- | --- | --- |
| LCP | 2,5 – 5 s | < 1 s |
| Maintenance | Plugins + core à jour | Quasi nulle |
| Sécurité | Surface d'attaque large | Pas de backend exposé |
| Hébergement | 10 – 50 €/mois | 0 – 5 €/mois |

## Et le contenu du blog ?

Pas besoin d'abandonner la simplicité d'un éditeur : un CMS headless (comme celui qui propulse ce blog) permet de continuer à rédiger dans une interface confortable, pendant que Next.js se charge de l'affichage.

Exemple de redirection 301 conservée côté Next.js :


// redirections-301.next.config.js — https://raw.githubusercontent.com/micmc422/blogfiles/refs/heads/main/migrer-wordpress-nextjs/redirections-301.next.config.js
```js
export default {
  async redirects() {
    return [{ source, destination, permanent: true }];
  },
};
```


## Combien ça coûte ?

Chaque projet est différent, mais l'ordre de grandeur pour un site vitrine se situe entre 2 000 et 6 000 € selon le périmètre. Le retour sur investissement se joue sur l'hébergement (souvent divisé par 5), la maintenance et les conversions gagnées grâce à la vitesse.
